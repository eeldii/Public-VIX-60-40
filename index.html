How this model works

Daily VIX closes are monitored during each calendar month; the resulting allocation is applied to the following month's return, avoiding look-ahead bias. Portfolio returns remain monthly because the bundled asset-price history is monthly. Each strategy rebalances when its target changes; the base portfolio stays at 60/40.

Transaction costs apply to traded notional: half the sum of absolute stock and bond weight changes, multiplied by portfolio value and the cost rate. The default transaction cost is 0.1% of traded notional.

All strategies use daily VIX closes from the prior calendar month to set the next month's allocation. The 60/40 reset occurs once VIX has remained below 25 for a full calendar month; a close at or above 25 restarts that waiting period. Daily signal changes are implemented at monthly boundaries in this model. Strategy 1 uses 70/30 above 25 and 80/20 above 30; Strategy 2 uses 80/20 above 25; Strategy 3 uses 70/30 above 25.

Data and assumptions

The three comparisons use the same monthly data, starting amount and transaction cost. All target mixes sum to 100%.

Use total return data for both asset classes, with matching monthly dates. VIX is observed daily from FRED; monthly returns use the prior calendar month's daily signal history. CAGR uses the full 321-month sample; volatility and Sharpe use monthly arithmetic returns annualized by √12. Sharpe assumes a 0% risk-free rate. Maximum drawdown measures the largest peak-to-trough loss.

Missing values, mismatched dates, or invalid returns are rejected rather than filled silently.

Data sourcing and proxy notes

Bundled adjusted-close history captured Oct 31, 2026 from Yahoo Finance: SPY represents the S&P 500, with distributions reinvested. For bonds, the series uses Vanguard Total Bond Market Index Fund (VBMFX) through Nov 2017; it tracks the Bloomberg U.S. Aggregate Float Adjusted Index. From Dec 2017 onward, it uses iShares Core Global Aggregate Bond UCITS ETF (AGGG.L), which tracks the Bloomberg Global Aggregate Bond Index. VBMFX is a U.S.-only aggregate bond proxy, so the benchmark changes at the splice; early-period results are not a pure global-bond backtest. Daily CBOE VIX closes (VIXCLS) are bundled from FRED (retrieved Oct 31, 2026). Adjusted closes reinvest distributions; fund expenses, tracking differences, and FX exposure affect returns. The data snapshot does not refresh automatically.
